# Todo List

A modern responsive Todo List web application.

## Features

- Add tasks
- Add due dates with a date picker
- Complete tasks
- Delete tasks
- Show each task's due date
- Highlight overdue tasks with a red warning
- LocalStorage persistence
- Responsive design

## Usage

Open `index.html` in your browser.

Enter a task, optionally choose a due date, and click **添加**. Tasks are saved in LocalStorage, so they remain after refreshing the page. If a task's due date is earlier than today, the app marks it in red and shows an overdue warning.
